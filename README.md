# GhostedIn: The Flattery Rejection Generator

A tongue-in-cheek single-page web application designed to grant job seekers instant, therapeutic closure from ghosting recruiters by generating lavishly flattering, custom rejection letters.

## Features
- **Zero Backend Required**: Runs completely client-side. Zero API keys, zero maintenance.
- **5 Satirical Archetypes**:
  - *Terror & Awe*: You are so competent that the VP of Operations is trembling.
  - *Cosmic & Spiritual*: Your aura cannot be confined within Jira sprints.
  - *Financial Ruin*: Hiring you would bankrupt the company's cap table.
  - *Boardroom Coup*: You would seize control of the board by Day 45.
  - *Tears & Mourning*: Archiving your CV required bagpipes and black armbands.
- **Realistic Parchment & Stamp**: Rendered on classic corporate stationery with an official "OVERQUALIFIED" rubber stamp.
- **Export Capabilities**:
  - One-click copy formatted text to clipboard.
  - High-res PNG export using `html2canvas` for sharing on LinkedIn or Twitter/X.
- **Confetti & Native Web Audio**: Instant celebration sound and visual effects upon letter generation.

## How to Deploy to GitHub Pages (Under 2 Minutes)

1. **Create a GitHub Repository**:
   - Go to [GitHub New Repo](https://github.com/new).
   - Name it `flattery-rejection-letter` (or whatever you like).
   - Set it to **Public**.

2. **Add Files**:
   - Upload `index.html` to the root of your repository.

3. **Turn on GitHub Pages**:
   - Head to your repository's **Settings** tab.
   - Click on **Pages** in the left sidebar.
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.

4. **Visit Your Site**:
   - In 30–60 seconds, your site will be live at:
     `https://<your-username>.github.io/<repo-name>/`
